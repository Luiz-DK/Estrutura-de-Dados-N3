##  Contexto Acadêmico
 
- **Instituição:** Universidade de Rio Verde (UniRV) — Campus Rio Verde

- **Disciplina:** Estrutura de Dados 1
- **Professor:** Vinícius Martinez de Oliveira
- **Conteúdo:** Listas Encadeadas — Lista Duplamente Encadeada (*Doubly Linked List*)
